# **OOP v TypeScriptu – Lekce 1: Naše první bubliny**

Vytvoříme jednoduchou aplikaci, která pomocí p5.js vykreslí tři statické bubliny. Každá bude mít jinou polohu, velikost a barvu.

## **1. Kompletní ukázka&#x20;**`main.ts`

```
import p5 from "p5";

// Třída představuje předpis pro vytváření bublin.
class Bublina {

  // Vlastnosti, které bude mít každá bublina.
  x: number;
  y: number;
  prumer: number;
  barva: string;

  // Konstruktor nastaví počáteční vlastnosti objektu.
  constructor(x: number, y: number, prumer: number, barva: string) {
    this.x = x;
    this.y = y;
    this.prumer = prumer;
    this.barva = barva;
  }

  // Metoda vykreslí bublinu na plátno p5.js.
  vykresli(p: p5): void {
    p.noStroke();
    p.fill(this.barva);
    p.circle(this.x, this.y, this.prumer);
  }
}

// Hlavní část programu využívající knihovnu p5.js.
const sketch = (p: p5) => {

  // Vytvoření tří samostatných instancí třídy Bublina.
  const b1 = new Bublina(120, 150, 60, "red");
  const b2 = new Bublina(300, 100, 90, "blue");
  const b3 = new Bublina(480, 200, 45, "green");

  // Příprava grafického prostředí.
  p.setup = () => {
    p.createCanvas(600, 320);
    p.noLoop();  // Statická grafika, bez opakování draw().
  };

  // Vykreslení všech tří bublin.
  p.draw = () => {
    p.background(240);

    b1.vykresli(p);
    b2.vykresli(p);
    b3.vykresli(p);
  };
};

// Spuštění grafické aplikace.
new p5(sketch);
```

Tento kód je možné použít v projektu Vite + TypeScript ve StackBlitzu po instalaci knihovny `p5` příkazem `npm install p5`.

## **2. Pět nejdůležitějších konstrukcí**

### **A. Třída**

```
class Bublina {
  // ...
}
```

Definuje společnou strukturu všech bublin. Zatím nevytváří žádnou konkrétní bublinu.

### **B. Vlastnosti**

```
x: number;
y: number;
prumer: number;
barva: string;
```

Každá instance má vlastní hodnoty těchto čtyř vlastností.

### **C. Konstruktor**

```
constructor(x: number, y: number, prumer: number, barva: string) {
  this.x = x;
  this.y = y;
  this.prumer = prumer;
  this.barva = barva;
}
```

Konstruktor se automaticky zavolá při vytvoření nové instance pomocí `new`.

Výraz `this.x` znamená vlastnost `x` aktuálního objektu, zatímco samotné `x` představuje parametr předaný konstruktoru.

### **D. Instance objektu**

```
const b1 = new Bublina(120, 150, 60, "red");
```

Operátor `new` vytvoří konkrétní objekt podle třídy `Bublina` a zavolá jeho konstruktor.

Tři instance jedné třídy

b1

(120, 150)

Průměr: 60

b2

(300, 100)

Průměr: 90

b3

(480, 200)

Průměr: 45

### **E. Metoda**

```
vykresli(p: p5): void {
  p.noStroke();
  p.fill(this.barva);
  p.circle(this.x, this.y, this.prumer);
}
```

Metoda určuje, co objekt umí dělat. V našem případě se každá bublina dokáže sama vykreslit.

Všechny instance používají stejnou metodu, ale vykreslují se podle svých vlastností:

```
b1.vykresli(p);
b2.vykresli(p);
b3.vykresli(p);
```

Právě zde se dobře ukazuje podstata OOP: **společný předpis, různé objekty a jejich vlastní data.**

## **3. První samostatné úkoly pro studenty**

Doporučuji začít jednoduchými úpravami, které nevyžadují znalost dalších konstrukcí.

1. Změňte polohu, barvu a velikost jedné bubliny.
2. Vytvořte čtvrtou instanci `b4` a vykreslete ji.
3. Doplňte do třídy metodu `plocha(): number`, která vypočítá obsah kruhu.
4. Přidejte metodu `zmenBarvu(novaBarva: string): void`, která upraví vlastnost `barva`, a použijte ji před vykreslením bubliny.
5. Vysvětlete, proč příkaz `b1.vykresli(p)` vykreslí jinou bublinu než `b2.vykresli(p)`, přestože oba objekty používají stejnou metodu.

## **4. Co bych v této fázi záměrně nevyučoval**

Zatím bych vynechal pole objektů, náhodné generování, `public` a `private`, metody polí, události, pohyb i dědičnost.

Rovněž bych prozatím zachoval delší podobu konstruktoru s explicitním přiřazováním pomocí `this`. Zkrácený zápis konstruktoru v TypeScriptu je vhodné vysvětlit až následně, protože studenti už budou rozumět tomu, co zkracuje.
