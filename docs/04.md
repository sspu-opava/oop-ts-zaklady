# **OOP v TypeScriptu – Lekce 4: Enkapsulace, vlastnosti a metody objektů**

V předchozích třech lekcích jsme postupně vytvořili třídu `Bublina`, naučili se ukládat její instance do pole a následně generovat libovolný počet bublin s náhodnými vlastnostmi.

Doposud však naše objekty uměly pouze jednu věc: vykreslit se na plátno.

Ve čtvrté lekci rozšíříme třídu o další schopnosti a seznámíme se s jedním z nejdůležitějších principů OOP – **enkapsulací neboli zapouzdřením**.

Budeme se učit:

- rozlišovat veřejné (`public`) a soukromé (`private`) vlastnosti;
- používat zkrácený zápis konstruktoru v TypeScriptu;
- vytvářet metody, které vracejí hodnoty;
- vytvářet metody, které mění stav objektu;
- využívat metody objektů při práci s polem.

**Bubliny zatím zůstanou statické.** Pohyb a animaci zařadíme až v další fázi.

## **2. Kompletní kód čtvrté lekce**

```

import p5 from "p5";

// TŘÍDA BUBLINA
// Každá bublina má vlastní vlastnosti a metody.
class Bublina {

  // Zkrácený konstruktor TypeScriptu.
  // Modifikátory public a private automaticky
  // vytvoří příslušné vlastnosti objektu.
  constructor(
    public x: number,
    public y: number,
    public prumer: number,
    private barva: string
  ) {}

  // Vykreslí bublinu podle jejích vlastností.
  vykresli(p: p5): void {
    p.noStroke();
    p.fill(this.barva);
    p.circle(this.x, this.y, this.prumer);
  }

  // Vypočítá plochu kruhu.
  plocha(): number {
    const r = this.prumer / 2;
    return Math.PI * r ** 2;
  }

  // Zjistí, zda zadaný bod leží uvnitř kruhu.
  obsahuje(x: number, y: number): boolean {
    const vzdalenost = Math.hypot(
      this.x - x,
      this.y - y
    );

    return vzdalenost < this.prumer / 2;
  }

  // Bezpečný způsob změny soukromé vlastnosti.
  zmenBarvu(novaBarva: string): void {
    if (novaBarva.trim() !== "") {
      this.barva = novaBarva;
    }
  }
}

// HLAVNÍ APLIKACE
const sketch = (p: p5) => {

  // Paleta barev.
  const barvy: string[] = [
    "#1cc5c9",
    "#fba24c",
    "#a38cf5",
    "#f779a0"
  ];

  // Pole instancí.
  let bubliny: Bublina[] = [];

  // Bod, který budeme testovat.
  const bodX = 300;
  const bodY = 160;

  // Vytvoření náhodné instance.
  function vytvorBublinu(): Bublina {
    return new Bublina(
      p.random(40, 560),
      p.random(40, 280),
      p.random(20, 70),
      p.random(barvy)
    );
  }

  p.setup = () => {
    p.createCanvas(600, 320);

    // Vygenerujeme 19 náhodných bublin.
    bubliny = Array.from(
      { length: 19 },
      () => vytvorBublinu()
    );

    // Přidáme jednu bublinu na známou pozici,
    // abychom mohli spolehlivě testovat obsahuje().
    const ukazkova = new Bublina(
      bodX, bodY, 70, "#a38cf5"
    );

    bubliny.push(ukazkova);

    // Ukázka metody, která vrací číslo.
    console.log("Plocha:", ukazkova.plocha());

    // Ukázka metody, která vrací boolean.
    console.log(
      "Bod uvnitř:",
      ukazkova.obsahuje(bodX, bodY)
    );

    // Vyhledáme bubliny obsahující zadaný bod
    // a změníme jejich barvu.
    bubliny.forEach((bublina) => {
      if (bublina.obsahuje(bodX, bodY)) {
        bublina.zmenBarvu("#ffb000");
      }
    });

    // Statická scéna.
    p.noLoop();
  };

  p.draw = () => {
    p.background(240);

    // Vykreslení všech objektů.
    bubliny.forEach((bublina) => {
      bublina.vykresli(p);
    });

    // Označení testovaného bodu.
    p.stroke(20);
    p.strokeWeight(2);
    p.line(bodX - 6, bodY, bodX + 6, bodY);
    p.line(bodX, bodY - 6, bodX, bodY + 6);

    p.noStroke();
    p.fill(20);
    p.textSize(14);
    p.text("Oranžové bubliny obsahují označený bod.", 15, 305);
  };
};

// Spuštění aplikace p5.js.
new p5(sketch);

```

Po spuštění uvidíme dvacet statických bublin. Jedna z nich bude určitě obsahovat bod `(300, 160)`. Všechny bubliny obsahující tento bod budou obarveny oranžově.

Nové metody tedy přímo ovlivňují výslednou grafiku.

## **3. Zkrácený konstruktor TypeScriptu**

V minulých lekcích jsme používali tento zápis:

```
class Bublina {
  x: number;
  y: number;
  prumer: number;
  barva: string;

  constructor(x: number, y: number, prumer: number, barva: string) {
    this.x = x;
    this.y = y;
    this.prumer = prumer;
    this.barva = barva;
  }
}
```

Tento způsob je správný, ale obsahuje značné množství opakujícího se kódu.

TypeScript nabízí zkrácený zápis nazývaný *parameter properties*:

```
class Bublina {
  constructor(
    public x: number,
    public y: number,
    public prumer: number,
    private barva: string
  ) {}
}
```

V jediném zápisu zde definujeme parametry konstruktoru, vytváříme odpovídající vlastnosti a přiřazujeme jim hodnoty.

Prázdné tělo konstruktoru `{}` je zcela v pořádku, protože inicializaci provede mechanismus TypeScriptu.

**Důležité:** Zápis `constructor(x: number)` sám o sobě nevytvoří vlastnost `this.x`. Aby vznikla pomocí tohoto zkráceného mechanismu, musí parametr obsahovat například modifikátor `public` nebo `private`.

## **4. Enkapsulace:&#x20;**`public`**&#x20;a&#x20;**`private`

Všimněme si následující části:

```
constructor(
  public x: number,
  public y: number,
  public prumer: number,
  private barva: string
) {}
```

Souřadnice a průměr jsou veřejné vlastnosti. Můžeme tedy přistupovat přímo k jejich hodnotám.

```
const b = new Bublina(100, 150, 60, "red");

console.log(b.x);       // 100
console.log(b.prumer);  // 60

b.x = 200;               // Povoleno
b.prumer = 80;           // Povoleno
```

Barva je ale soukromá:

```
console.log(b.barva); // Chyba TypeScriptu
```

Přístup k ní je povolen pouze uvnitř deklarující třídy.

**Veřejné a soukromé vlastnosti**

**Objekt&#x20;**`Bublina`

**Veřejné vlastnosti**

`x`, `y`, `prumer`

Přístupné z ostatních částí programu.

**Soukromá vlastnost**

`barva`

Přímý přístup je omezen na kód třídy.

Řízená změna vlastnosti

`zmenBarvu(novaBarva)`

Smyslem enkapsulace není pouze zabránit přístupu k datům. Jde také o to, že objekt může **určovat pravidla, podle kterých se jeho vlastnosti mění**.

U modifikátoru `private` v TypeScriptu je vhodné připomenout, že se kontroluje především při typové analýze. Na rozdíl od JavaScriptových polí `#barva` nejde o skutečné soukromí vynucované běhovým prostředím.

## **5. Metoda&#x20;**`zmenBarvu()`**&#x20;– změna stavu objektu**

```
zmenBarvu(novaBarva: string): void {
  if (novaBarva.trim() !== "") {
    this.barva = novaBarva;
  }
}
```

Tato metoda představuje jednoduchý způsob kontrolované změny soukromé vlastnosti.

Například:

```
const b = new Bublina(100, 150, 60, "red");

b.zmenBarvu("blue");
```

Metoda nejprve ověří, že předaný řetězec není prázdný ani složený pouze z mezer.

Potom změní hodnotu `this.barva`.

Kontrola pomocí `trim()` ovšem nezaručuje, že jde o platný zápis CSS barvy. V této lekci nám stačí jednoduchá demonstrace principu.

### **Metody, které mění stav, a metody, které vracejí hodnotu**

Rozlišujme dvě situace:

```
b.zmenBarvu("blue");
```

Metoda změní stav existujícího objektu a nic nevrací. Její návratový typ je `void`.

Naproti tomu:

```
const obsah = b.plocha();
```

metoda vypočítá a vrátí číselnou hodnotu. Samotný objekt se přitom nemění.

## **6. Metoda&#x20;**`plocha()`**&#x20;– výpočet z vlastností objektu**

```
plocha(): number {
  const r = this.prumer / 2;
  return Math.PI * r ** 2;
}
```

Metoda využívá vlastnost `prumer`, která patří aktuální instanci.

Vzorec pro plochu kruhu je:

\\[ S=\pi r^2 \\]

Například pro bublinu s průměrem 60 pixelů:

\\[ r=30,\qquad S=\pi\cdot30^2\approx2827{,}43\\;\text{px}^2 \\]

Použití:

```
const b = new Bublina(100, 150, 60, "red");

console.log(b.plocha());
```

Výhodou je, že nemusíme opakovaně psát celý matematický vzorec. Samotná bublina má metodu, která umí její plochu vypočítat.

To odpovídá jedné ze základních myšlenek OOP: **spojovat data a operace nad těmito daty do jednoho objektu**.

## **7. Metoda&#x20;**`obsahuje()`**&#x20;– geometrický test**

```
obsahuje(x: number, y: number): boolean {
  const vzdalenost = Math.hypot(
    this.x - x,
    this.y - y
  );

  return vzdalenost < this.prumer / 2;
}
```

Metoda zjistí, zda bod se souřadnicemi `(x, y)` leží uvnitř bubliny.

Používá přitom vzdálenost mezi dvěma body v rovině:

\\[ d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2} \\]

Funkce `Math.hypot()` provede tento výpočet za nás.

Pokud je vzdálenost bodu od středu menší než poloměr, metoda vrátí `true`.

### **Interaktivní demonstrace**

Souřadnice X: 200

Souřadnice Y: 110

Metoda obsahuje() vrací true.

Proč máme tuto metodu ve třídě?

Protože bublina sama zná svou polohu a průměr. Není potřeba, aby jiná část programu znovu počítala její poloměr a vzdálenost testovaného bodu.

V další lekci, kdy přidáme interakci s myší, nám bude tato metoda velmi užitečná.

## **8. Jak metody využíváme v hlavní aplikaci?**

Nejdůležitější částí naší ukázky je tento kód:

```
bubliny.forEach((bublina) => {
  if (bublina.obsahuje(bodX, bodY)) {
    bublina.zmenBarvu("#ffb000");
  }
});
```

Zde se propojuje práce s polem a OOP.

Program postupně prochází všechny instance uložené v poli `bubliny`.

Pro každou instanci:

1. Zavolá metodu `obsahuje()`.
2. Vyhodnotí vrácenou logickou hodnotu.
3. Pokud bod leží uvnitř bubliny, zavolá `zmenBarvu()`.

Všimněte si, že podmínka vůbec nepracuje s výpočtem vzdálenosti nebo poloměru. Tyto detaily jsou ukryty uvnitř metody `obsahuje()`.

To je praktický příklad zapouzdření: vnější kód nemusí znát vnitřní implementaci objektových metod, stačí mu jejich rozhraní a chování.

## **11. Shrnutí čtvrté lekce**

Dostali jsme se k důležitému posunu v chápání OOP. Naše objekty už neslouží pouze k uchovávání vlastností a vykreslování kruhů. Každá bublina nyní dokáže poskytovat informace o svém stavu a některé své vlastnosti kontrolovaně měnit.

Rozšířili jsme třídu o tři metody s odlišným účelem:

| Metoda             | Návratový typ | Účel               |
| ------------------ | ------------- | ------------------ |
| `plocha()`         | `number`      | Vypočítá plochu    |
| `obsahuje(x, y)`   | `boolean`     | Otestuje bod       |
| `zmenBarvu(barva)` | `void`        | Změní stav objektu |

Naučili jsme se také, že modifikátory `public` a `private` pomáhají definovat rozhraní objektu a omezovat přímý přístup k jeho vnitřním datům.
