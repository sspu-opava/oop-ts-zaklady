# **OOP v TypeScriptu – Lekce 8: Různé chování objektů**

V sedmé lekci jsme vytvořili tři třídy – `Kruh`, `Ctverec` a `Trojuhelnik` –, které dědí od společné abstraktní třídy `GrafickyObjekt`.

Jednotlivé objekty se lišily především svým vzhledem, způsobem výpočtu plochy a geometrickým testem, zda obsahují určitý bod.

V osmé, závěrečné lekci si ukážeme, že **polymorfismus můžeme využít nejen pro vykreslování, ale také pro rozdílné chování objektů**.

Zachováme běžný pohyb a odrazy od okrajů. Nepotřebujeme žádné vlnové funkce ani složitější matematiku.

Místo toho zavedeme jednoduchou interakci: **kliknutí na objekt vyvolá u každého geometrického tvaru jinou reakci**.

## **1. Co bude aplikace dělat?**

**Kruh**

Změní barvu

**Čtverec**

Zvětší se

**Trojúhelník**

Zmenší se

Všechny objekty dostanou stejný pokyn `klikni()`, ale každý jej provede odlišně.

To je hlavní myšlenka osmé lekce.

Nebudeme se ptát, zda byl kliknutý objekt kruh, čtverec nebo trojúhelník. Každému jednoduše zavoláme:

```
objekt.klikni();
```

Samotný objekt rozhodne, co se stane.

## **2. První úprava: Nová abstraktní metoda**

Začneme jednoduchou změnou rodičovské třídy.

Do `GrafickyObjekt` přidáme jediný řádek:

```
abstract klikni(): void;
```

Rodičovská třída nyní předepisuje, že každý konkrétní grafický objekt musí umět reagovat na kliknutí.

```
abstract class GrafickyObjekt {
  // Společné vlastnosti a metody...

  abstract vykresli(p: p5): void;
  abstract plocha(): number;
  abstract obsahuje(x: number, y: number): boolean;

  // NOVINKA:
  abstract klikni(): void;
}
```

Tato metoda nemá žádné tělo.

Její skutečnou implementaci vytvoříme až v potomcích.

## **3. Druhá úprava: Každý potomek reaguje jinak**

### **Kruh – změna barvy**

Do třídy `Kruh` přidáme:

```
override klikni(): void {
  if (this.barva === "#f779a0") {
    this.barva = "#1cc5c9";
  } else {
    this.barva = "#f779a0";
  }
}
```

Kruh po kliknutí přepne barvu mezi růžovou a tyrkysovou. Pokud měl původně jinou barvu, první kliknutí ji změní na růžovou.

Využíváme vlastnost `barva`, která je v rodičovské třídě označena jako `protected`. Proto s ní mohou pracovat také potomci.

### **Čtverec – zvětšení**

Do třídy `Ctverec` přidáme:

```
override klikni(): void {
  this.velikost = Math.min(
    this.velikost + 8,
    90
  );
}
```

Každé kliknutí zvětší stranu čtverce o osm pixelů.

Funkce `Math.min()` zajistí, že velikost nepřekročí 90 pixelů.

### **Trojúhelník – zmenšení**

Do třídy `Trojuhelnik` přidáme:

```
override klikni(): void {
  this.velikost = Math.max(
    this.velikost - 8,
    16
  );
}
```

Trojúhelník se naopak bude zmenšovat. Díky `Math.max()` však jeho velikost neklesne pod 16 pixelů.

Právě jsme vytvořili tři různé implementace téže metody.

## **4. Kompletní kód osmé lekce**

Pro přehlednost zachováme strukturu předchozí aplikace a všechny dosavadní důležité metody.

Studenti mohou kód opět vložit do souboru `src/main.ts` v projektu Vite + TypeScript + p5.js.

```

import p5 from "p5";

// ==========================================
// 1. KONSTANTY A TYPY
// ==========================================

const SIRKA = 600;
const VYSKA = 320;
const PANEL = 60;

type DruhTvaru = "kruh" | "ctverec" | "trojuhelnik";


// ==========================================
// 2. SPOLEČNÁ RODIČOVSKÁ TŘÍDA
// ==========================================

abstract class GrafickyObjekt {

  constructor(
    public x: number,
    public y: number,
    public velikost: number,
    protected barva: string,
    private vx: number,
    private vy: number
  ) {}

  // Tuto metodu dědí všechny tři druhy objektů.
  pohyb(p: p5): void {
    this.x += this.vx;
    this.y += this.vy;

    const r = this.velikost / 2;

    // Odraz od levého a pravého okraje.
    if (this.x < r || this.x > SIRKA - r) {
      this.vx *= -1;
      this.x = p.constrain(this.x, r, SIRKA - r);
    }

    // Odraz od horního a dolního okraje.
    if (this.y < r || this.y > VYSKA - r) {
      this.vy *= -1;
      this.y = p.constrain(this.y, r, VYSKA - r);
    }
  }

  // Společné rozhraní všech potomků.
  abstract vykresli(p: p5): void;
  abstract plocha(): number;
  abstract obsahuje(x: number, y: number): boolean;

  // NOVINKA: Každý potomek bude reagovat jinak.
  abstract klikni(): void;
}


// ==========================================
// 3. TŘÍDA KRUH
// ==========================================

class Kruh extends GrafickyObjekt {

  override vykresli(p: p5): void {
    p.noStroke();
    p.fill(this.barva);
    p.circle(this.x, this.y, this.velikost);
  }

  override plocha(): number {
    const r = this.velikost / 2;
    return Math.PI * r ** 2;
  }

  override obsahuje(x: number, y: number): boolean {
    return Math.hypot(this.x - x, this.y - y)
      <= this.velikost / 2;
  }

  // Po kliknutí kruh změní barvu.
  override klikni(): void {
    if (this.barva === "#f779a0") {
      this.barva = "#1cc5c9";
    } else {
      this.barva = "#f779a0";
    }
  }
}


// ==========================================
// 4. TŘÍDA ČTVEREC
// ==========================================

class Ctverec extends GrafickyObjekt {

  override vykresli(p: p5): void {
    p.noStroke();
    p.fill(this.barva);

    const s = this.velikost;
    p.square(this.x - s / 2, this.y - s / 2, s);
  }

  override plocha(): number {
    return this.velikost ** 2;
  }

  override obsahuje(x: number, y: number): boolean {
    const r = this.velikost / 2;

    return (
      Math.abs(x - this.x) <= r &&
      Math.abs(y - this.y) <= r
    );
  }

  // Po kliknutí se čtverec zvětší.
  override klikni(): void {
    this.velikost = Math.min(
      this.velikost + 8,
      90
    );
  }
}


// ==========================================
// 5. TŘÍDA TROJÚHELNÍK
// ==========================================

class Trojuhelnik extends GrafickyObjekt {

  override vykresli(p: p5): void {
    p.noStroke();
    p.fill(this.barva);

    const s = this.velikost;

    p.triangle(
      this.x,       this.y - s / 2,
      this.x - s/2, this.y + s / 2,
      this.x + s/2, this.y + s / 2
    );
  }

  override plocha(): number {
    return this.velikost ** 2 / 2;
  }

  override obsahuje(x: number, y: number): boolean {
    const s = this.velikost;
    const dx = Math.abs(x - this.x);
    const dy = y - this.y;

    return (
      dy >= -s / 2 &&
      dy <= s / 2 &&
      dx <= (dy + s / 2) / 2
    );
  }

  // Po kliknutí se trojúhelník zmenší.
  override klikni(): void {
    this.velikost = Math.max(
      this.velikost - 8,
      16
    );
  }
}


// ==========================================
// 6. HLAVNÍ APLIKACE
// ==========================================

const sketch = (p: p5) => {

  const barvy = [
    "#1cc5c9",
    "#fba24c",
    "#a38cf5",
    "#f779a0"
  ];

  const druhy: DruhTvaru[] = [
    "kruh",
    "ctverec",
    "trojuhelnik"
  ];

  // Polymorfní pole objektů.
  let objekty: GrafickyObjekt[] = [];

  // Druh nově přidávaného objektu.
  let vybranyDruh: DruhTvaru = "kruh";


  // ----------------------------------------
  // VYTVOŘENÍ KONKRÉTNÍHO OBJEKTU
  // ----------------------------------------

  function vytvorObjekt(
    x: number,
    y: number,
    druh: DruhTvaru
  ): GrafickyObjekt {

    const s = p.random(25, 70);
    const r = s / 2;

    const px = p.constrain(x, r, SIRKA - r);
    const py = p.constrain(y, r, VYSKA - r);

    const barva = p.random(barvy);
    const vx = p.random(-2.5, 2.5);
    const vy = p.random(-2.5, 2.5);

    switch (druh) {
      case "kruh":
        return new Kruh(px, py, s, barva, vx, vy);

      case "ctverec":
        return new Ctverec(px, py, s, barva, vx, vy);

      case "trojuhelnik":
        return new Trojuhelnik(px, py, s, barva, vx, vy);
    }
  }


  // ----------------------------------------
  // OBNOVENÍ SCÉNY
  // ----------------------------------------

  function obnov(): void {
    objekty = Array.from({ length: 15 }, () => {
      const x = p.random(45, SIRKA - 45);
      const y = p.random(45, VYSKA - 45);

      return vytvorObjekt(x, y, p.random(druhy));
    });
  }


  // ----------------------------------------
  // KONTROLA POLOHY MYŠI
  // ----------------------------------------

  function mysVeScene(): boolean {
    return (
      p.mouseX >= 0 &&
      p.mouseX < SIRKA &&
      p.mouseY >= 0 &&
      p.mouseY < VYSKA
    );
  }


  // ----------------------------------------
  // INICIALIZACE
  // ----------------------------------------

  p.setup = () => {
    p.createCanvas(SIRKA, VYSKA + PANEL);
    obnov();
  };


  // ----------------------------------------
  // ANIMAČNÍ SMYČKA
  // ----------------------------------------

  p.draw = () => {
    p.background("#f0f0f0");

    objekty.forEach((objekt) => {
      objekt.pohyb(p);
      objekt.vykresli(p);
    });

    // Polymorfní výpočet součtu ploch.
    const celkovaPlocha = objekty.reduce(
      (soucet, objekt) => soucet + objekt.plocha(),
      0
    );

    // Informační panel.
    p.noStroke();
    p.fill("#dce4ec");
    p.rect(0, VYSKA, SIRKA, PANEL);

    p.fill("#243347");
    p.textSize(13);

    p.text(
      `Objektů: ${objekty.length} | ` +
      `Plocha: ${Math.round(celkovaPlocha)} px² | ` +
      `Nový: ${vybranyDruh}`,
      12, VYSKA + 22
    );

    p.text(
      "Klik: změň/přidej | 1–3: typ | D: smaž | S: seřaď | R: obnov",
      12, VYSKA + 45
    );
  };


  // ----------------------------------------
  // NOVINKA: KLIKNUTÍ NA OBJEKT
  // ----------------------------------------

  p.mousePressed = () => {

    if (!mysVeScene()) return;

    // Procházíme pole od konce.
    // Přednost dostane naposledy vykreslený
    // objekt, tedy ten, který je nahoře.
    for (let i = objekty.length - 1; i >= 0; i--) {

      const objekt = objekty[i];

      if (objekt.obsahuje(p.mouseX, p.mouseY)) {

        // POLYMORFISMUS:
        // Stejné volání, ale různé chování.
        objekt.klikni();

        return;
      }
    }

    // Pokud jsme neklikli na žádný objekt,
    // vytvoříme novou instanci.
    objekty.push(
      vytvorObjekt(
        p.mouseX,
        p.mouseY,
        vybranyDruh
      )
    );
  };


  // ----------------------------------------
  // OVLÁDÁNÍ KLÁVESNICÍ
  // ----------------------------------------

  p.keyPressed = () => {

    switch (p.key.toLowerCase()) {

      case "1":
        vybranyDruh = "kruh";
        break;

      case "2":
        vybranyDruh = "ctverec";
        break;

      case "3":
        vybranyDruh = "trojuhelnik";
        break;

      case "d":
        if (mysVeScene()) {
          objekty = objekty.filter(
            (objekt) =>
              !objekt.obsahuje(p.mouseX, p.mouseY)
          );
        }
        break;

      case "s":
        objekty.sort(
          (a, b) => a.velikost - b.velikost
        );
        break;

      case "r":
        obnov();
        break;
    }
  };
};

// Spuštění grafické aplikace.
new p5(sketch);

```

## **5. Kde přesně se projevuje polymorfismus?**

Nejdůležitější částí programu je tato:

```
if (objekt.obsahuje(p.mouseX, p.mouseY)) {
  objekt.klikni();
  return;
}
```

Všimněte si, že neobsahuje žádné rozhodování podle druhu geometrického tvaru.

Nemusíme psát:

```
if (objekt instanceof Kruh) {
  // Změnit barvu
} else if (objekt instanceof Ctverec) {
  // Zvětšit objekt
} else if (objekt instanceof Trojuhelnik) {
  // Zmenšit objekt
}
```

Takový zápis by sice mohl fungovat, ale zbytečně by přenášel znalost konkrétních druhů objektů do hlavního programu.

Místo toho máme:

```
objekt.klikni();
```

Protože všechny tři třídy implementují metodu `klikni()`, může ji hlavní program zavolat na libovolném objektu.

Konkrétní implementace se vybere podle skutečné třídy instance.

`objekt.klikni()`

Jednotné volání v hlavním programu

Kruh

Změní barvu

Čtverec

Zvětší se

Trojúhelník

Zmenší se

**Jeden společný název metody, ale tři různá chování – to je názorná demonstrace polymorfismu.**

## **6. Proč procházíme pole od konce?**

V události `mousePressed()` používáme:

```
for (let i = objekty.length - 1; i >= 0; i--) {
  const objekt = objekty[i];

  if (objekt.obsahuje(p.mouseX, p.mouseY)) {
    objekt.klikni();
    return;
  }
}
```

V předchozích lekcích jsme většinou procházeli pole od začátku.

Nyní však chceme, aby při překrytí několika objektů reagoval ten, který vidíme nahoře.

Protože v `draw()` vykreslujeme objekty v pořadí pole, poslední objekt se vykreslí jako poslední a překryje ostatní.

Při hledání kliknutého objektu proto postupujeme opačně.

Příkaz `return` zajistí, že po nalezení prvního zasaženého objektu funkce skončí.

Pokud žádný objekt nenajdeme, vytvoříme novou instanci vybraného typu.

Tím získáváme dvě intuitivní operace:

- Kliknutí na existující objekt vyvolá jeho individuální reakci.
- Kliknutí na prázdné místo vytvoří nový objekt.

## **7. Proč je toto řešení výhodné při rozšiřování programu?**

Představme si, že bychom později chtěli doplnit čtvrtý objekt – například `Hvezda`.

Tato nová třída by zdědila společné vlastnosti a metodu `pohyb()` z `GrafickyObjekt`.

Současně by implementovala vlastní metody `vykresli()`, `plocha()`, `obsahuje()` a `klikni()`.

Například:

```
override klikni(): void {
  this.velikost = 50;
}
```

Po zařazení nové třídy do vytváření objektů by již existující kód pro jejich zpracování mohl zůstat beze změny:

```
objekty.forEach((objekt) => {
  objekt.pohyb(p);
  objekt.vykresli(p);
});
```

Stejně tak:

```
objekt.klikni();
```

Tento přístup představuje jeden z hlavních přínosů polymorfismu: aplikaci lze rozšiřovat o nové konkrétní typy, aniž bychom museli opakovaně upravovat každé místo, které s objekty pracuje.

## **10. Závěrečné shrnutí celého osmidílného projektu**

V průběhu osmi lekcí jsme z jednoduché aplikace se třemi statickými kruhy postupně vytvořili interaktivní grafický simulátor, který využívá důležité principy objektově orientovaného programování.

| Lekce | Hlavní učivo                                   | Výsledné rozšíření                |
| ----- | ---------------------------------------------- | --------------------------------- |
| 1     | Třída, konstruktor, instance, `this`           | Tři statické bubliny              |
| 2     | Pole objektů, `push()`, `forEach()`            | Společné zpracování instancí      |
| 3     | `random()`, `Array.from()`                     | Náhodné generování objektů        |
| 4     | `public`, `private`, metody                    | Výpočty a řízená změna vlastností |
| 5     | Aktualizace stavu, animace                     | Pohyb a odrazy                    |
| 6     | Události, `filter()`, `sort()`, `reduce()`     | Interaktivní simulátor            |
| 7     | `extends`, `abstract`, `protected`, `override` | Dědičnost a různé tvary           |
| **8** | **Polymorfní chování objektů**                 | **Různé reakce na kliknutí**      |

Pro závěrečnou lekci je nejdůležitější pochopit rozdíl mezi dvěma situacemi.

Při dědičnosti říkáme: **„Tyto objekty mají společné vlastnosti a část chování.“**

Při polymorfismu říkáme: **„S těmito objekty mohu pracovat stejným způsobem, ale každý může konkrétní požadavek vykonat jinak.“**

Záměrně jsme použili pouze změnu barvy a velikosti. Studenti tak mohou soustředit pozornost na samotnou architekturu tříd a fungování polymorfismu, aniž by jejich pochopení komplikovala matematika vlnových funkcí nebo složitější simulace pohybu.

Tím je základní osmidílný kurz OOP v TypeScriptu uzavřen.
