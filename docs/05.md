# **OOP v TypeScriptu – Lekce 5: Pohyb objektů a odrazy od okrajů**

V předchozích čtyřech lekcích jsme postupně vytvořili třídu `Bublina`, naučili se vytvářet její instance, ukládat je do pole, automaticky generovat objekty s náhodnými vlastnostmi a používat metody pro práci s jejich stavem.

Dosud však byly všechny bubliny statické.

V páté lekci je konečně uvedeme do pohybu. **Každá bublina bude mít vlastní rychlost a směr pohybu. Při dosažení okraje kreslicí plochy se odrazí a bude pokračovat opačným směrem.**

Tím se dostáváme k důležitému principu objektově orientovaného programování: **objekt uchovává svůj stav a prostřednictvím svých metod jej může průběžně měnit.**

## **1. Co se změní oproti čtvrté lekci?**

| Oblast              | Lekce 4                                               | Lekce 5                             |
| ------------------- | ----------------------------------------------------- | ----------------------------------- |
| Souřadnice `x`, `y` | Neměnily se                                           | Průběžně se aktualizují             |
| Rychlost            | Neexistovala                                          | Nové soukromé vlastnosti `vx`, `vy` |
| Konstruktor         | Čtyři parametry                                       | Šest parametrů                      |
| Metody              | `vykresli()`, `plocha()`, `obsahuje()`, `zmenBarvu()` | Navíc `pohyb()`                     |
| `p.setup()`         | Obsahoval `noLoop()`                                  | Animace zůstane spuštěná            |
| `p.draw()`          | Pouze vykreslování                                    | Pohyb a následné vykreslení         |
| Chování objektů     | Statické                                              | Pohyb a odrazy od stěn              |

Prozatím nebudeme řešit srážky mezi bublinami, ovládání myší ani změny jejich počtu během animace. Tato témata zařadíme do dalších lekcí.

## **2. Kompletní kód páté lekce**

Následující program přímo navazuje na předchozí verzi. Zachovává existující třídu a její metody, ale doplňuje rychlost a pohyb.

Soubor `src/main.ts`:

```

import p5 from "p5";

// --------------------------------------------------
// TŘÍDA BUBLINA
// --------------------------------------------------

class Bublina {

  // Konstruktor vytvoří vlastnosti objektu.
  // Souřadnice a průměr jsou veřejné.
  // Barva a rychlosti jsou soukromé.
  constructor(
    public x: number,
    public y: number,
    public prumer: number,
    private barva: string,
    private vx: number,
    private vy: number
  ) {}

  // NOVÁ METODA: Pohyb bubliny
  pohyb(p: p5): void {

    // Změníme souřadnice podle rychlosti.
    this.x += this.vx;
    this.y += this.vy;

    // Poloměr potřebujeme pro kontrolu okrajů.
    const r = this.prumer / 2;

    // Odraz od levého nebo pravého okraje.
    if (this.x < r || this.x > p.width - r) {

      // Obrátíme vodorovnou rychlost.
      this.vx *= -1;

      // Zajistíme, aby bublina zůstala na plátně.
      this.x = p.constrain(this.x, r, p.width - r);
    }

    // Odraz od horního nebo dolního okraje.
    if (this.y < r || this.y > p.height - r) {

      // Obrátíme svislou rychlost.
      this.vy *= -1;

      // Omezíme svislou souřadnici.
      this.y = p.constrain(this.y, r, p.height - r);
    }
  }

  // Vykreslení bubliny na aktuální pozici.
  vykresli(p: p5): void {
    p.noStroke();
    p.fill(this.barva);
    p.circle(this.x, this.y, this.prumer);
  }

  // Výpočet plochy kruhu.
  plocha(): number {
    const r = this.prumer / 2;
    return Math.PI * r ** 2;
  }

  // Zjištění, zda bod leží uvnitř bubliny.
  obsahuje(x: number, y: number): boolean {
    const vzdalenost = Math.hypot(
      this.x - x,
      this.y - y
    );

    return vzdalenost < this.prumer / 2;
  }

  // Kontrolovaná změna barvy.
  zmenBarvu(novaBarva: string): void {
    if (novaBarva.trim() !== "") {
      this.barva = novaBarva;
    }
  }
}

// --------------------------------------------------
// HLAVNÍ APLIKACE p5.js
// --------------------------------------------------

const sketch = (p: p5) => {

  // Paleta barev.
  const barvy: string[] = [
    "#1cc5c9",
    "#fba24c",
    "#a38cf5",
    "#f779a0"
  ];

  // Pole všech instancí třídy Bublina.
  let bubliny: Bublina[] = [];

  // Počet vytvářených objektů.
  const pocetBublin = 20;

  // Funkce vytvoří jednu náhodnou bublinu.
  function vytvorBublinu(): Bublina {

    // Nejprve zvolíme náhodný průměr.
    const prumer = p.random(20, 70);
    const r = prumer / 2;

    // Souřadnice volíme tak, aby bublina
    // vznikla celá uvnitř kreslicí plochy.
    const x = p.random(r, p.width - r);
    const y = p.random(r, p.height - r);

    // Náhodná barva z připravené palety.
    const barva = p.random(barvy);

    // Náhodné rychlosti v obou směrech.
    const vx = p.random(-2.5, 2.5);
    const vy = p.random(-2.5, 2.5);

    // Vrátíme novou instanci třídy.
    return new Bublina(
      x, y, prumer, barva, vx, vy
    );
  }

  // Inicializace grafického prostředí.
  p.setup = () => {

    // Vytvoření kreslicí plochy.
    p.createCanvas(600, 320);

    // Automatické vytvoření 20 instancí.
    bubliny = Array.from(
      { length: pocetBublin },
      () => vytvorBublinu()
    );

    // noLoop() již nepoužíváme.
    // Funkce draw() se bude opakovat.
  };

  // Hlavní animační smyčka.
  p.draw = () => {

    // Smazání předchozího snímku.
    p.background(240);

    // Aktualizace a vykreslení všech objektů.
    bubliny.forEach((bublina) => {

      // Nejprve vypočítáme novou pozici.
      bublina.pohyb(p);

      // Poté vykreslíme objekt.
      bublina.vykresli(p);
    });
  };
};

// Spuštění aplikace.
new p5(sketch);

```

Pro spuštění použijeme stejný projekt Vite + TypeScript + p5.js ve StackBlitzu. Soubor `index.html` nemusíme oproti předchozí lekci upravovat.

Výsledkem bude dvacet barevných bublin, které se pohybují různými směry a různou rychlostí. Jakmile některá dosáhne hranice canvasu, změní směr.

## **3. Nové vlastnosti objektu:&#x20;**`vx`**&#x20;a&#x20;**`vy`

Základní změnou v naší třídě je rozšíření konstruktoru o dvě nové vlastnosti:

```
private vx: number,
private vy: number
```

Tyto vlastnosti představují rychlost v jednotlivých směrech.

- `vx` (*velocity x*) – vodorovná složka rychlosti.
- `vy` (*velocity y*) – svislá složka rychlosti.

V souřadnicovém systému p5.js začínají souřadnice v levém horním rohu plátna. Osa X směřuje doprava, zatímco osa Y směřuje dolů.

Kladná vodorovná rychlost znamená pohyb doprava. Kladná svislá rychlost znamená pohyb dolů.

| `vx` | `vy` | Směr pohybu         |
| ---- | ---- | ------------------- |
| 2    | 0    | Doprava             |
| −2   | 0    | Doleva              |
| 0    | 2    | Dolů                |
| 0    | −2   | Nahoru              |
| 2    | 1    | Šikmo doprava dolů  |
| −2   | −1   | Šikmo doleva nahoru |

Proč jsou rychlosti deklarované jako `private`?

Protože chceme, aby jejich změny řídily metody samotného objektu. Například metoda `pohyb()` rozhoduje, kdy je potřeba rychlost obrátit při nárazu do okraje.

To je další příklad **zapouzdření v OOP**.

## **4. Metoda&#x20;**`pohyb()`**&#x20;– změna stavu objektu**

Nejdůležitější novou metodou je:

```
pohyb(p: p5): void {
  this.x += this.vx;
  this.y += this.vy;

  // ...
}
```

Zatím se soustřeďme pouze na první dva příkazy.

```
this.x += this.vx;
this.y += this.vy;
```

Zápis `+=` znamená přičtení a přiřazení. První řádek je tedy ekvivalentní příkazu:

```
this.x = this.x + this.vx;
```

Představme si bublinu vytvořenou takto:

```
const b = new Bublina(
  100, 150, 40, "blue", 3, -2
);
```

Počáteční souřadnice jsou `(100, 150)` a při každém zavolání `pohyb()` se X zvýší o 3 a Y sníží o 2.

| Volání         | `x` | `y` |
| -------------- | --- | --- |
| Počáteční stav | 100 | 150 |
| 1.             | 103 | 148 |
| 2.             | 106 | 146 |
| 3.             | 109 | 144 |
| 4.             | 112 | 142 |
| 5.             | 115 | 140 |

Každá bublina přitom používá stejnou metodu `pohyb()`, ale pracuje s vlastními hodnotami souřadnic a rychlostí.

**Základní princip:** Metoda mění vlastnosti konkrétní instance, nikoli společné hodnoty celé třídy.

## **5. Jak funguje odraz od okraje?**

Pohybující se objekt by bez dalších omezení časem opustil kreslicí plochu. Proto potřebujeme kontrolovat jeho polohu.

### **A. Výpočet poloměru**

```
const r = this.prumer / 2;
```

Souřadnice `x` a `y` určují střed kruhu. Při kontrole okrajů však potřebujeme zohlednit i jeho poloměr.

Pokud je průměr 40 pixelů, poloměr je 20 pixelů.

Na canvasu o šířce 600 pixelů se tedy střed bubliny může nacházet mezi souřadnicemi 20 a 580.

### **B. Kontrola vodorovných hranic**

```
if (this.x < r || this.x > p.width - r) {
  this.vx *= -1;
  this.x = p.constrain(this.x, r, p.width - r);
}
```

Podmínka se skládá ze dvou částí propojených operátorem `||`, který znamená logické NEBO.

Kontrolujeme, zda bublina překročila levou nebo pravou hranici.

Pokud ano, vykoná se:

```
this.vx *= -1;
```

Rychlost změní znaménko.

Například `vx = 3` se změní na `vx = -3`. Bublina se začne pohybovat opačným směrem.

### **C. Proč používáme&#x20;**`constrain()`**?**

Po přičtení rychlosti už může být střed objektu za povolenou hranicí. Pouhé otočení rychlosti by jej tam v daném snímku ponechalo.

Funkce:

```
p.constrain(this.x, r, p.width - r)
```

omezí hodnotu souřadnice na přípustný interval.&#x20;

### **D. Odraz od horního a dolního okraje**

Druhá část metody pracuje obdobně:

```
if (this.y < r || this.y > p.height - r) {
  this.vy *= -1;
  this.y = p.constrain(this.y, r, p.height - r);
}
```

Rozdíl spočívá pouze v tom, že místo X a `vx` používáme souřadnici Y a svislou rychlost `vy`.

Protože jsou tyto dvě kontroly nezávislé, dokáže se bublina odrazit i v rohu, kde se obrátí obě složky rychlosti.

Tento jednoduchý model předpokládá dokonale pružný odraz od pevných stěn. Neřeší ztráty energie ani vzájemné srážky bublin.

## **6. Co se změnilo v&#x20;**`setup()`**&#x20;a&#x20;**`draw()`**?**

V předchozí lekci jsme používali:

```
p.noLoop();
```

Tento příkaz zastaví opakované vykonávání funkce `draw()`.

Pro animaci jej musíme odstranit.

Podle dokumentace p5.js se funkce `draw()` standardně snaží vykonávat přibližně 60krát za sekundu, skutečná frekvence však závisí na výkonu zařízení.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://p5js.org\&sz=32)

p5js.org+1



Naše nová animační smyčka:

```
p.draw = () => {
  p.background(240);

  bubliny.forEach((bublina) => {
    bublina.pohyb(p);
    bublina.vykresli(p);
  });
};
```

V každém snímku tedy provedeme tři operace:

1. Vymažeme předchozí snímek pomocí `background()`.
2. Všem objektům vypočítáme nové souřadnice pomocí `pohyb()`.
3. Všechny objekty vykreslíme na nových pozicích.

Pořadí je důležité. Kdybychom pozadí nepřekreslovali, pohybující se kruhy by zanechávaly stopy.

### **Dvě varianty procházení pole**

Studenti už znají metodu `forEach()`:

```
bubliny.forEach((bublina) => {
  bublina.pohyb(p);
  bublina.vykresli(p);
});
```

Stejný výsledek získáme pomocí klasického cyklu:

```
for (const bublina of bubliny) {
  bublina.pohyb(p);
  bublina.vykresli(p);
}
```

Důležité je, že **nepotřebujeme vytvářet nové instance pro každý snímek**. V poli zůstávají stále stejné objekty, kterým se pouze mění jejich vlastnosti.

## **7. Nový význam stavu objektu**

V první lekci jsme objekty vnímali především jako soubory vlastností:

```
x
y
prumer
barva
```

Nyní však přibyl dynamický stav:

```
vx
vy
```

Bublina už není pouze statickým grafickým prvkem. Je samostatným objektem, jehož stav se vyvíjí v čase.

Získáváme tím důležité rozdělení:

| Typ metody   | Příklad       | Význam                         |
| ------------ | ------------- | ------------------------------ |
| Aktualizační | `pohyb()`     | Mění stav objektu              |
| Vykreslovací | `vykresli()`  | Vytváří grafickou reprezentaci |
| Výpočetní    | `plocha()`    | Vrací hodnotu                  |
| Testovací    | `obsahuje()`  | Vrací logický výsledek         |
| Modifikační  | `zmenBarvu()` | Kontrolovaně mění vlastnost    |

Všimněme si, že metody `plocha()`, `obsahuje()` a `zmenBarvu()` jsme nemuseli při přidání pohybu nijak měnit.

To je jedna z výhod oddělení odpovědností uvnitř třídy.

## **10. Shrnutí páté lekce**

V této lekci jsme poprvé vytvořili **dynamické objekty**, které průběžně mění svůj stav.

Naše třída `Bublina` nyní obsahuje šest vlastností a pět metod. Každá instance má vlastní souřadnice, velikost, barvu a rychlost. Přesto všechny používají stejnou implementaci pohybu.

Naučili jsme se také, jak funguje animační smyčka p5.js a jak lze prostřednictvím podmínek a změny znaménka rychlosti simulovat odrazy od hranic.

Pro první verzi je dostačující, že rychlosti představují počet pixelů za snímek. V pokročilejší simulaci bychom měli využít časový krok `p.deltaTime`, abychom zajistili přibližně stejnou rychlost i na počítačích s různou snímkovou frekvencí.

### **Co bude následovat v šesté lekci?**

Doporučuji doplnit **interakci s uživatelem a pokročilejší práci s polem instancí**:

- Kliknutí myší přidá novou bublinu.
- Klávesa `D` odstraní bubliny nacházející se pod ukazatelem pomocí `filter()`.
- Klávesa `S` seřadí bubliny podle průměru pomocí `sort()`.
- Klávesa `R` obnoví simulaci.
- Metoda `reduce()` vypočítá celkovou plochu všech bublin.

Tím bychom dokončili základní simulátor a získali dobrý výchozí bod pro následující fázi: **dědičnost a polymorfismus**, při které vedle bublin vytvoříme další třídy pohybujících se grafických objektů.
