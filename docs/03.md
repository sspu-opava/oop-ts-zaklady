# **OOP v TypeScriptu – Lekce 3: Automatické vytváření objektů**

V předchozí lekci jsme vytvořili třídu `Bublina`, její instance ukládali do pole `Bublina[]` a všechny objekty vykreslovali pomocí metody `forEach()`.

Zatím jsme však každou bublinu vytvářeli ručně:

```
bubliny.push(new Bublina(120, 150, 60, "red"));
bubliny.push(new Bublina(300, 100, 90, "blue"));
bubliny.push(new Bublina(480, 200, 45, "green"));
```

Co když chceme vytvořit 20, 50 nebo třeba 100 bublin? A co když má mít každá bublina jinou velikost, polohu a barvu?

Ve třetí lekci se naučíme **automaticky generovat libovolný počet instancí třídy s náhodnými vlastnostmi**.

Zachováme přitom jednoduchost předchozích příkladů: bubliny budou stále statické a nebudou reagovat na uživatelské události.

## **2. Kompletní kód třetí lekce**

Celý příklad opět umístíme do souboru `src/main.ts`. Předpokládáme stejný projekt Vite + TypeScript + p5.js, jaký jsme používali v předchozích dvou lekcích.

```

import p5 from "p5";

// TŘÍDA BUBLINA
// Každá bublina má vlastní polohu, průměr a barvu.
class Bublina {
  x: number;
  y: number;
  prumer: number;
  barva: string;

  // Konstruktor inicializuje vlastnosti nové instance.
  constructor(x: number, y: number, prumer: number, barva: string) {
    this.x = x;
    this.y = y;
    this.prumer = prumer;
    this.barva = barva;
  }

  // Metoda vykreslí aktuální objekt.
  vykresli(p: p5): void {
    p.noStroke();
    p.fill(this.barva);
    p.circle(this.x, this.y, this.prumer);
  }
}

// HLAVNÍ APLIKACE
const sketch = (p: p5) => {

  // Paleta barev, ze které budeme náhodně vybírat.
  const barvy: string[] = [
    "#1cc5c9",
    "#fba24c",
    "#a38cf5",
    "#f779a0"
  ];

  // Pole pro uložení vytvořených instancí.
  let bubliny: Bublina[] = [];

  // Počet bublin, které chceme vygenerovat.
  const pocetBublin = 20;

  // Pomocná funkce vytvoří jednu náhodnou bublinu.
  function vytvorBublinu(): Bublina {
    const x = p.random(40, 560);
    const y = p.random(40, 280);
    const prumer = p.random(20, 70);
    const barva = p.random(barvy);

    return new Bublina(x, y, prumer, barva);
  }

  // Inicializace grafického prostředí.
  p.setup = () => {
    p.createCanvas(600, 320);

    // Vytvoříme pole obsahující 20 nových bublin.
    bubliny = Array.from(
      { length: pocetBublin },
      () => vytvorBublinu()
    );

    // Vykreslení proběhne pouze jednou.
    p.noLoop();
  };

  // Vykreslení celé scény.
  p.draw = () => {
    p.background(240);

    // Pro každou bublinu zavoláme její metodu.
    bubliny.forEach((bublina) => {
      bublina.vykresli(p);
    });
  };
};

// Spuštění aplikace.
new p5(sketch);

```

Při každém novém spuštění aplikace vznikne jiné rozmístění barevných kruhů. Po vykreslení však bubliny zůstávají na stejných pozicích.

Všimněte si, že **třída&#x20;**`Bublina`**&#x20;je úplně stejná jako v předchozí lekci**. Změnili jsme pouze způsob vytváření jejích instancí. To je jedna z důležitých výhod objektově orientovaného programování.

## **3. Jak funguje náhodné generování vlastností?**

Začněme jednoduchou funkcí `p.random()`, kterou známe z p5.js.

### **A. Náhodná čísla**

```
const x = p.random(40, 560);
const y = p.random(40, 280);
const prumer = p.random(20, 70);
```

Funkce `p.random(min, max)` vrátí náhodné číslo z intervalu od `min` včetně až po `max`, které samo do intervalu nepatří. Výsledek je obvykle desetinné číslo.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://p5js.org\&sz=32)

p5js.org



V našem programu používáme náhodná čísla pro tři vlastnosti:

| Vlastnost | Interval | Význam                      |
| --------- | -------- | --------------------------- |
| `x`       | 40–560   | Vodorovná poloha středu     |
| `y`       | 40–280   | Svislá poloha středu        |
| `prumer`  | 20–70    | Velikost bubliny v pixelech |

Proč nepoužíváme celé rozměry canvasu 600 × 320?

Protože souřadnice představují střed kruhu. Kdyby například střed bubliny s průměrem 70 ležel na `x = 590`, část kruhu by se nacházela mimo kreslicí plochu.

Zvolené intervaly ponechávají kolem obrazovky dostatečný prostor.

Nezaručují však, že se jednotlivé bubliny nebudou překrývat. Prozatím je to v pořádku.

### **B. Náhodný výběr z pole**

Barvu vybíráme jiným způsobem:

```
const barvy: string[] = [
  "#1cc5c9",
  "#fba24c",
  "#a38cf5",
  "#f779a0"
];

const barva = p.random(barvy);
```

Metoda `p.random()` umí kromě náhodných čísel vybírat také náhodný prvek z pole.

V tomto případě tedy vrátí jeden ze čtyř barevných řetězců.

Všechny čtyři položky mají stejnou pravděpodobnost výběru, tedy 25 %.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://p5js.org\&sz=32)

p5js.org



To je podstatně jednodušší než generovat náhodný index a následně pomocí něj přistupovat do pole.

## **4. Funkce&#x20;**`vytvorBublinu()`**&#x20;– oddělení vytváření objektů**

```
function vytvorBublinu(): Bublina {
  const x = p.random(40, 560);
  const y = p.random(40, 280);
  const prumer = p.random(20, 70);
  const barva = p.random(barvy);

  return new Bublina(x, y, prumer, barva);
}
```

Všimněte si, že tato funkce není metodou třídy `Bublina`. Je samostatnou funkcí uvnitř `sketch`.

Jejím úkolem je připravit náhodné hodnoty a vytvořit jednu instanci.

Zvláštní pozornost si zaslouží návratový typ:

```
function vytvorBublinu(): Bublina
```

Dvojtečka za seznamem parametrů určuje, jaký typ hodnoty funkce vrací. Zde je výsledkem objekt typu `Bublina`.

Příkaz:

```
return new Bublina(x, y, prumer, barva);
```

vytvoří instanci a vrátí ji volajícímu.

Tento přístup bývá označován jako *factory function* – funkce sloužící k vytváření objektů.

### **Proč náhodné hodnoty nevytváříme přímo v konstruktoru?**

Mohli bychom. Pro výuku je však výhodnější ponechat konstruktor jednoduchý.

```
new Bublina(100, 150, 40, "red");
```

Stále dokážeme vytvořit objekt s přesně zadanými vlastnostmi.

A pokud potřebujeme objekt s náhodnými vlastnostmi, použijeme:

```
vytvorBublinu();
```

Tím oddělujeme **samotný objekt od způsobu, jakým volíme jeho počáteční hodnoty**.

## **5.&#x20;**`Array.from()`**&#x20;– vytvoření celého pole objektů**

Nyní přichází nejdůležitější nová konstrukce:

```
bubliny = Array.from(
  { length: pocetBublin },
  () => vytvorBublinu()
);
```

Metoda `Array.from()` zde vytvoří nové pole, které bude obsahovat požadovaný počet výsledků volání funkce `vytvorBublinu()`.

Rozložme si konstrukci na jednotlivé části.

Anatomie zápisu `Array.from()`

bubliny = Array.from(

　{ length: pocetBublin },

　() => vytvorBublinu()

);

`{ length: pocetBublin }`

Určuje, že nové pole bude obsahovat například 20 prvků.

`() => vytvorBublinu()`

Šipková funkce se zavolá pro každý vytvářený prvek a vrátí novou instanci.

`bubliny = ...`

Výsledné pole instancí přiřadíme do proměnné `bubliny`.

### **Co se děje při vykonávání?**

Při `pocetBublin = 20` se funkce `vytvorBublinu()` zavolá dvacetkrát. Každé volání vytvoří samostatnou instanci se samostatně vygenerovanými hodnotami.

Výsledné pole můžeme schematicky znázornit takto:

```
bubliny = [
  Bublina,  // Instance 0
  Bublina,  // Instance 1
  Bublina,  // Instance 2
  // ...
  Bublina   // Instance 19
];
```

Nejde o dvacet odkazů na tutéž bublinu, ale o dvacet nezávislých objektů.

### **Ekvivalent pomocí cyklu&#x20;**`for`

Stejný výsledek bychom mohli získat pomocí:

```
bubliny = [];

for (let i = 0; i < pocetBublin; i++) {
  const novaBublina = vytvorBublinu();
  bubliny.push(novaBublina);
}
```

Pro začínající programátory může být cyklus `for` srozumitelnější. Metoda `Array.from()` však elegantně spojuje vytvoření pole s jeho naplněním.

## **7. Proč je zde&#x20;**`p.noLoop()`**?**

```
p.setup = () => {
  p.createCanvas(600, 320);

  bubliny = Array.from(
    { length: pocetBublin },
    () => vytvorBublinu()
  );

  p.noLoop();
};
```

Funkce `p.noLoop()` zastaví opakované provádění `draw()`. Úvodní vykreslení však proběhne.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://p5js.org\&sz=32)

p5js.org



V našem programu bubliny nemění své vlastnosti, takže je zbytečné celou scénu vykreslovat přibližně šedesátkrát za sekundu.

Je důležité, že náhodné generování probíhá v `setup()`, nikoliv v `draw()`. Bubliny se proto nebudou znovu vytvářet při každém překreslení.

Později, až přidáme pohyb, budeme potřebovat opakované vykreslování a `p.noLoop()` odstraníme.
