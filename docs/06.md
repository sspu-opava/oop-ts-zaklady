# **OOP v TypeScriptu – Lekce 6: Interaktivní objekty a pokročilá práce s poli**

Události myši a klávesnice, metody `push()`, `filter()`, `sort()`, `reduce()` a spolupráce objektů

V předchozích pěti lekcích jsme postupně vytvořili třídu `Bublina`, její instance ukládali do pole, generovali jim náhodné vlastnosti a nakonec je rozpohybovali. Každá bublina má vlastní polohu, průměr, barvu a rychlost. Pomocí metody `pohyb()` aktualizuje svůj stav a pomocí `vykresli()` se zobrazuje na canvasu.

Nyní vytvoříme **interaktivní simulátor**, který bude reagovat na uživatele. Procvičíme si především práci s polem objektů a událostmi.

## **1. Co se v šesté lekci naučíme?**

| Akce uživatele | Výsledek                   | Použitá konstrukce                |
| -------------- | -------------------------- | --------------------------------- |
| Kliknutí myší  | Vytvoření nové bubliny     | `mousePressed()`, `new`, `push()` |
| Klávesa D      | Odstranění bublin pod myší | `filter()`, `obsahuje()`          |
| Klávesa S      | Seřazení podle průměru     | `sort()`                          |
| Klávesa R      | Vygenerování nové scény    | `Array.from()`                    |
| Každý snímek   | Výpočet součtu ploch       | `reduce()`, `plocha()`            |

Oproti páté fázi zůstane základní princip pohybu beze změny. Rozšíříme pouze hlavní program o reakce na uživatelské události a zpracování pole.

Zároveň začneme výrazněji rozlišovat dvě úrovně programu: samotný objekt `Bublina` a aplikaci, která organizuje kolekci těchto objektů.

## **2. Jak bude aplikace vypadat?**

Ilustrace rozhraní: horní oblast slouží k pohybu bublin, spodní pruh zobrazuje informační údaje a ovládání. Skutečný počet a součet ploch se budou průběžně měnit.

Prostor canvasu rozdělíme na dvě části: 600 × 320 pixelů pro bubliny a spodních 55 pixelů pro informace. Celkové rozměry canvasu budou 600 × 375 pixelů.

Toto uspořádání nám umožní zachovat rozměry původní pohybové scény a současně zajistit, že bubliny nebudou zasahovat do textového panelu.

## **3. Kompletní kód šesté lekce**

Použijeme dosavadní projekt Vite + TypeScript + p5.js ve StackBlitzu. Soubor `index.html` zůstane stejný.

Do `src/main.ts` vložíme následující kód.

```

import p5 from "p5";

// --------------------------------------------------
// KONSTANTY APLIKACE
// --------------------------------------------------

// Rozměry kreslicí plochy.
const SIRKA = 600;
const VYSKA_SCENY = 320;
const VYSKA_PANELU = 55;

// Výchozí počet bublin.
const POCET_BUBLIN = 20;

// Rozsah velikostí.
const MIN_PRUMER = 20;
const MAX_PRUMER = 70;


// --------------------------------------------------
// TŘÍDA BUBLINA
// --------------------------------------------------

class Bublina {

  // Konstruktor inicializuje vlastnosti instance.
  // Každá bublina má vlastní polohu, velikost,
  // barvu a dvě složky rychlosti.
  constructor(
    public x: number,
    public y: number,
    public prumer: number,
    private barva: string,
    private vx: number,
    private vy: number
  ) {}

  // Aktualizace polohy a odrazy od okrajů.
  pohyb(p: p5): void {

    // Posun podle rychlosti.
    this.x += this.vx;
    this.y += this.vy;

    const r = this.prumer / 2;

    // Odraz od levého a pravého okraje.
    if (this.x < r || this.x > p.width - r) {
      this.vx *= -1;
      this.x = p.constrain(this.x, r, p.width - r);
    }

    // Odraz od horní a dolní hranice scény.
    // Spodní informační panel není součástí
    // prostoru, v němž se bubliny pohybují.
    if (this.y < r || this.y > VYSKA_SCENY - r) {
      this.vy *= -1;
      this.y = p.constrain(this.y, r, VYSKA_SCENY - r);
    }
  }

  // Vykreslení bubliny.
  vykresli(p: p5): void {
    p.noStroke();
    p.fill(this.barva);
    p.circle(this.x, this.y, this.prumer);
  }

  // Výpočet plochy kruhu.
  plocha(): number {
    const r = this.prumer / 2;
    return Math.PI * r ** 2;
  }

  // Určí, zda zadaný bod leží uvnitř bubliny.
  obsahuje(x: number, y: number): boolean {
    const vzdalenost = Math.hypot(
      this.x - x,
      this.y - y
    );

    return vzdalenost < this.prumer / 2;
  }

  // Kontrolovaná změna soukromé vlastnosti.
  zmenBarvu(novaBarva: string): void {
    if (novaBarva.trim() !== "") {
      this.barva = novaBarva;
    }
  }
}


// --------------------------------------------------
// HLAVNÍ APLIKACE p5.js
// --------------------------------------------------

const sketch = (p: p5) => {

  // Barvy používané při vytváření bublin.
  const barvy: string[] = [
    "#1cc5c9",
    "#fba24c",
    "#a38cf5",
    "#f779a0"
  ];

  // Pole obsahující instance třídy Bublina.
  // Používáme let, protože budeme celé pole
  // nahrazovat novým polem při filtrování a obnově.
  let bubliny: Bublina[] = [];


  // ------------------------------------------------
  // VYTVOŘENÍ JEDNÉ BUBLINY
  // ------------------------------------------------

  function vytvorBublinu(x: number, y: number): Bublina {

    // Náhodný průměr a poloměr.
    const prumer = p.random(MIN_PRUMER, MAX_PRUMER);
    const r = prumer / 2;

    // Zajistíme, že nová bublina vznikne celá
    // uvnitř povolené části canvasu.
    const bezpecneX = p.constrain(x, r, p.width - r);
    const bezpecneY = p.constrain(y, r, VYSKA_SCENY - r);

    // Vrátíme novou instanci.
    return new Bublina(
      bezpecneX,
      bezpecneY,
      prumer,
      p.random(barvy),
      p.random(-2.5, 2.5),
      p.random(-2.5, 2.5)
    );
  }


  // ------------------------------------------------
  // OBNOVENÍ CELÉHO POLE OBJEKTŮ
  // ------------------------------------------------

  function obnov(): void {

    // Maximální poloměr zajistí dostatečný odstup
    // nových bublin od hranic scény.
    const okraj = MAX_PRUMER / 2;

    // Vytvoříme nové pole s 20 instancemi.
    bubliny = Array.from(
      { length: POCET_BUBLIN },
      () => {
        const x = p.random(okraj, p.width - okraj);
        const y = p.random(okraj, VYSKA_SCENY - okraj);

        return vytvorBublinu(x, y);
      }
    );
  }


  // ------------------------------------------------
  // KONTROLA POLOHY MYŠI
  // ------------------------------------------------

  function mysVeScene(): boolean {

    // Vrátíme true pouze tehdy, pokud se myš
    // nachází uvnitř prostoru pro bubliny.
    return (
      p.mouseX >= 0 &&
      p.mouseX < p.width &&
      p.mouseY >= 0 &&
      p.mouseY < VYSKA_SCENY
    );
  }


  // ------------------------------------------------
  // INICIALIZACE
  // ------------------------------------------------

  p.setup = () => {

    // Horní scéna a spodní informační panel.
    p.createCanvas(SIRKA, VYSKA_SCENY + VYSKA_PANELU);

    // Vytvoření počátečních bublin.
    obnov();
  };


  // ------------------------------------------------
  // ANIMAČNÍ SMYČKA
  // ------------------------------------------------

  p.draw = () => {

    // Vymazání předchozího snímku.
    p.background(240);

    // Každé bublině aktualizujeme polohu
    // a následně ji vykreslíme.
    bubliny.forEach((bublina) => {
      bublina.pohyb(p);
      bublina.vykresli(p);
    });

    // NOVINKA: reduce()
    // Vypočítáme součet ploch všech bublin.
    const celkovaPlocha = bubliny.reduce(
      (soucet, bublina) => soucet + bublina.plocha(),
      0
    );

    // Vykreslení informačního panelu.
    p.noStroke();
    p.fill("#dce4ec");
    p.rect(0, VYSKA_SCENY, p.width, VYSKA_PANELU);

    // Textové informace.
    p.fill("#243347");
    p.textSize(14);

    p.text(
      `Počet bublin: ${bubliny.length} | ` +
      `Součet ploch: ${Math.round(celkovaPlocha)} px²`,
      12, 341
    );

    p.textSize(13);
    p.text(
      "Klik = přidat | D = smazat | S = seřadit | R = obnovit",
      12, 363
    );
  };


  // ------------------------------------------------
  // KLIKNUTÍ MYŠÍ
  // ------------------------------------------------

  p.mousePressed = () => {

    // Kliknutí mimo pohybovou oblast ignorujeme.
    if (!mysVeScene()) return;

    // NOVINKA: push()
    // Vytvoříme a přidáme novou instanci do pole.
    bubliny.push(
      vytvorBublinu(p.mouseX, p.mouseY)
    );
  };


  // ------------------------------------------------
  // OVLÁDÁNÍ KLÁVESNICÍ
  // ------------------------------------------------

  p.keyPressed = () => {

    // Převedeme písmeno na malé, aby fungovalo
    // například D i d.
    switch (p.key.toLowerCase()) {

      case "d":

        // NOVINKA: filter()
        // Odstraníme všechny bubliny pod myší.
        // Pokud myš není ve scéně, nic nemažeme.
        if (mysVeScene()) {
          bubliny = bubliny.filter(
            (b) => !b.obsahuje(p.mouseX, p.mouseY)
          );
        }
        break;

      case "s":

        // NOVINKA: sort()
        // Seřadíme pole podle průměru vzestupně.
        bubliny.sort(
          (a, b) => a.prumer - b.prumer
        );
        break;

      case "r":

        // Vytvoříme zcela novou sadu bublin.
        obnov();
        break;
    }
  };
};


// --------------------------------------------------
// SPUŠTĚNÍ APLIKACE
// --------------------------------------------------

new p5(sketch);

```

Tato verze je kompletní a zachovává základní principy předchozích lekcí. Především si všimněte, že **není potřeba vytvářet žádnou další třídu**. Veškeré nové možnosti vznikají vhodným využitím existujících instancí a metod polí.

## **4. První novinka: Událost&#x20;**`mousePressed()`

Doposud aplikace vytvářela bubliny pouze při inicializaci.

Nyní může uživatel vytvářet další objekty kliknutím.

```
p.mousePressed = () => {
  if (!mysVeScene()) return;

  bubliny.push(
    vytvorBublinu(p.mouseX, p.mouseY)
  );
};
```

Funkce `mousePressed()` je událostní obsluha (*event handler*). Knihovna p5.js ji vyvolá při stisknutí tlačítka myši.

Hodnoty `p.mouseX` a `p.mouseY` představují aktuální polohu myši v souřadnicovém systému canvasu.

### **Co znamená&#x20;**`if (!mysVeScene()) return;`**?**

Jde o běžný programátorský postup označovaný jako *guard clause*.

```
if (!mysVeScene()) return;
```

Pokud se myš nachází mimo scénu, funkce okamžitě skončí.

Jinak program pokračuje příkazem `push()`.

Tím zabráníme přidávání nových bublin do spodní informační oblasti nebo mimo canvas.

## **5. Metoda&#x20;**`push()`**&#x20;– změna existujícího pole**

```
bubliny.push(
  vytvorBublinu(p.mouseX, p.mouseY)
);
```

Tato konstrukce spojuje dvě operace.

Nejprve funkce `vytvorBublinu()` vytvoří novou instanci `Bublina` se souřadnicemi odvozenými z kliknutí.

Potom metoda `push()` přidá vytvořenou instanci na konec pole.

Pokud pole dosud obsahovalo 20 bublin, po kliknutí bude obsahovat 21.

Zásadní je, že `push()`**&#x20;mění existující pole**. Nevytváří nové pole a nemění žádné již existující bubliny.

## **6. Metoda&#x20;**`filter()`**&#x20;– odstraňování objektů**

Po stisknutí klávesy D se provede:

```
bubliny = bubliny.filter(
  (b) => !b.obsahuje(p.mouseX, p.mouseY)
);
```

Metoda `filter()` projde všechny prvky a vytvoří nové pole obsahující pouze objekty, pro které je podmínka pravdivá.

Zde využijeme metodu `obsahuje()`, kterou jsme vytvořili již ve čtvrté lekci.

```
b.obsahuje(p.mouseX, p.mouseY)
```

Vrací `true`, pokud se myš nachází uvnitř dané bubliny.

My ovšem používáme vykřičník:

```
!b.obsahuje(p.mouseX, p.mouseY)
```

Ten logickou hodnotu obrátí.

Význam je tedy: **ponech bubliny, které neobsahují pozici myši**.

Zjednodušená ukázka: objekty B2 a B4 jsou označeny k odstranění. Po filtrování zůstanou pouze B1 a B3.

### **Proč potřebujeme&#x20;**`let bubliny`**?**

Protože při filtrování přiřazujeme do proměnné nové pole:

```
bubliny = bubliny.filter(...);
```

Kdyby byla proměnná deklarována pomocí `const`, takové opětovné přiřazení by TypeScript nepovolil.

Metoda `filter()` tedy funguje jinak než `push()`:

| Metoda     | Co provede            |
| ---------- | --------------------- |
| `push()`   | Změní existující pole |
| `filter()` | Vrátí nové pole       |

Ještě jeden důležitý detail: Pokud se několik bublin překrývá pod ukazatelem myši, `filter()` může odstranit všechny současně. Neodstraňuje pouze první nalezený objekt.

## **7. Metoda&#x20;**`sort()`**&#x20;– řazení objektů podle vlastnosti**

Po stisknutí klávesy S se vykoná:

```
bubliny.sort(
  (a, b) => a.prumer - b.prumer
);
```

Metoda `sort()` seřadí prvky pole.

Protože pracujeme s objekty, musíme určit, podle které vlastnosti mají být seřazeny.

V našem případě je touto vlastností `prumer`.

Porovnávací funkce:

```
(a, b) => a.prumer - b.prumer
```

vrací záporné číslo, pokud má být `a` před `b`, kladné číslo, pokud má být až za ním, a nulu pro ekvivalentní hodnoty.

**Důležité upozornění:** V naší skutečné aplikaci `sort()` nemění souřadnice bublin.

Na canvasu se proto po stisknutí S objekty nepřesunou do řady podle velikosti. Změní se jejich pořadí v poli a tím také pořadí vykreslování.

Protože větší bubliny budou po seřazení vykresleny později, mohou při překrytí zakrývat menší.

Na rozdíl od `filter()` metoda `sort()` mění existující pole přímo.

Pokud bychom chtěli zachovat původní pořadí, mohli bychom vytvořit seřazenou kopii:

```
const serazene = [...bubliny].sort(
  (a, b) => a.prumer - b.prumer
);
```

## **8. Metoda&#x20;**`reduce()`**&#x20;– výpočet součtu ploch**

Poslední důležitou novinkou je:

```
const celkovaPlocha = bubliny.reduce(
  (soucet, bublina) => soucet + bublina.plocha(),
  0
);
```

Zatímco `filter()` vybírá objekty a `sort()` mění jejich pořadí, `reduce()` zpracovává prvky pole a vytváří jednu výslednou hodnotu.

V tomto případě sečteme plochy všech bublin.

Metoda využívá dříve vytvořenou objektovou metodu:

```
bublina.plocha()
```

To je podstatné. Vnější kód nepotřebuje vědět, jak se plocha kruhu počítá. Stačí mu zavolat příslušnou metodu objektu.

Představme si tři bubliny s plochami 200, 300 a 500 pixelů čtverečních.

| Krok | Dosavadní součet | Plocha bubliny | Výsledek |
| ---- | ---------------- | -------------- | -------- |
| 1    | 0                | 200            | 200      |
| 2    | 200              | 300            | 500      |
| 3    | 500              | 500            | 1 000    |

Počáteční hodnota `0` je důležitá zejména tehdy, když pole neobsahuje žádný prvek.

V takovém případě nám `reduce()` vrátí nulu.

Pokud se bubliny vzájemně překrývají, jejich překrývající se plochy se započítávají opakovaně. Vypočítáváme tedy součet ploch jednotlivých objektů, nikoliv skutečnou celkovou plochu pokrytou kruhy na canvasu.

## **9. Metoda&#x20;**`obnov()`**&#x20;– proč znovu používáme&#x20;**`Array.from()`**?**

Při stisknutí klávesy R zavoláme:

```
obnov();
```

Tato funkce vytvoří novou sadu bublin:

```
function obnov(): void {
  const okraj = MAX_PRUMER / 2;

  bubliny = Array.from(
    { length: POCET_BUBLIN },
    () => {
      const x = p.random(okraj, p.width - okraj);
      const y = p.random(okraj, VYSKA_SCENY - okraj);

      return vytvorBublinu(x, y);
    }
  );
}
```

Metodu `Array.from()` známe již ze třetí lekce.

Novinkou není samotná konstrukce, ale její využití v interaktivní aplikaci. Stejnou funkci, kterou jsme použili při inicializaci, můžeme kdykoliv znovu zavolat.

Původní pole nahradíme novým a další vykreslení již automaticky pracuje s novými objekty.

Tím se vyhneme opakování stejného kódu na několika místech aplikace.

## **10. Přehled hlavních metod polí**

V této lekci jsme využili několik metod, které se liší nejen svým účelem, ale také tím, zda mění původní pole.

| Metoda         | Výsledek                        | Mění původní pole? |
| -------------- | ------------------------------- | ------------------ |
| `push()`       | Přidá prvek a vrátí novou délku | Ano                |
| `filter()`     | Nové pole vybraných prvků       | Ne                 |
| `sort()`       | Seřazené pole                   | Ano                |
| `reduce()`     | Jedna výsledná hodnota          | Ne                 |
| `forEach()`    | Provede funkci pro každý prvek  | Sama o sobě ne     |
| `Array.from()` | Nově vytvořené pole             | Ne                 |

U `forEach()` může předaná funkce měnit objekty uložené v poli. Samotná metoda však prvky automaticky nenahrazuje ani neodstraňuje.

Toto rozlišení je pro další programování v TypeScriptu velmi důležité.

## **13. Co jsme se naučili?**

Dokončili jsme základní interaktivní aplikaci, v níž jednotlivé instance třídy `Bublina` samostatně aktualizují svůj stav, ale jejich vytváření, ukládání, vyhledávání a odstraňování organizuje společný program.

Z hlediska OOP je důležité především rozdělení odpovědností:

**Třída&#x20;**`Bublina` ví, jak se konkrétní objekt pohybuje, vykresluje a jak lze vypočítat jeho plochu nebo zjistit, zda obsahuje zadaný bod.

**Hlavní aplikace** ví, kolik objektů existuje, kdy je potřeba vytvořit další, které odstranit a jak zpracovat celou kolekci.

Tento způsob rozdělení kódu nám umožní aplikaci dále rozšiřovat bez zásadního přepisování již hotových částí.

### **Návrh sedmé fáze: Dědičnost a polymorfismus**

V další lekci bych doporučil přidat vedle bublin také čtverce a trojúhelníky.

Místo vytváření tří zcela nezávislých tříd nejprve definujeme společného předka, například `GrafickyObjekt`. Ten bude obsahovat společné vlastnosti a metody.

Třídy `Kruh`, `Ctverec` a `Trojuhelnik` následně vytvoříme pomocí `extends`. Každá bude mít vlastní podobu metody `vykresli()`.

Tím studentům ukážeme **dědičnost, přepisování metod a polymorfismus** na již známém grafickém programu.
