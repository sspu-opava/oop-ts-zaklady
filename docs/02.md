# **OOP v TypeScriptu – Lekce 2: Pole objektů a jejich vykreslování**

V první lekci jsme vytvořili třídu `Bublina` a tři její instance. Každá bublina měla vlastní souřadnice, průměr a barvu. Následně jsme každou vykreslili pomocí metody `vykresli()`.

Nyní uděláme další krok: **naučíme se ukládat instance třídy do pole a zpracovávat je společně**.

Zatím nebudeme používat náhodné generování ani pohyb. Bubliny zůstanou statické, aby se studenti mohli soustředit na nové programovací principy.

## **1. Proč potřebujeme pole objektů?**

V předchozím příkladu jsme používali:

```
const b1 = new Bublina(120, 150, 60, "red");
const b2 = new Bublina(300, 100, 90, "blue");
const b3 = new Bublina(480, 200, 45, "green");
```

Každý objekt jsme museli pojmenovat a samostatně vykreslit:

```
b1.vykresli(p);
b2.vykresli(p);
b3.vykresli(p);
```

Pro tři objekty to není problém. Co kdybychom ale potřebovali zobrazit 50 nebo 100 bublin?

Řešením je pole, které bude obsahovat všechny instance.

**Tři samostatné proměnné versus jedno pole objektů**

Samostatné proměnné

b1

b2

b3

Pole `Bublina[]`

[0]

[1]

[2]

Jedna proměnná `bubliny`

Každý prvek pole obsahuje odkaz na samostatnou instanci třídy `Bublina`.

## **2. Kompletní kód druhé lekce**

Oproti první lekci měníme pouze způsob vytvoření a vykreslení objektů. Třída `Bublina` zůstává beze změny.

```

import p5 from "p5";

// Třída představuje předpis pro vytváření bublin.
class Bublina {

  // Vlastnosti každé instance.
  x: number;
  y: number;
  prumer: number;
  barva: string;

  // Konstruktor nastaví počáteční hodnoty vlastností.
  constructor(x: number, y: number, prumer: number, barva: string) {
    this.x = x;
    this.y = y;
    this.prumer = prumer;
    this.barva = barva;
  }

  // Metoda vykreslí konkrétní bublinu.
  vykresli(p: p5): void {
    p.noStroke();
    p.fill(this.barva);
    p.circle(this.x, this.y, this.prumer);
  }
}

// Hlavní část aplikace p5.js.
const sketch = (p: p5) => {

  // Vytvoříme prázdné pole pro instance třídy Bublina.
  const bubliny: Bublina[] = [];

  // Do pole postupně přidáme tři nové objekty.
  bubliny.push(new Bublina(120, 150, 60, "red"));
  bubliny.push(new Bublina(300, 100, 90, "blue"));
  bubliny.push(new Bublina(480, 200, 45, "green"));

  // Inicializace kreslicí plochy.
  p.setup = () => {
    p.createCanvas(600, 320);
    p.noLoop(); // Statická grafika.
  };

  // Vykreslení celé scény.
  p.draw = () => {
    p.background(240);

    // Projdeme všechny objekty uložené v poli.
    bubliny.forEach((bublina) => {
      bublina.vykresli(p);
    });
  };
};

// Spuštění aplikace.
new p5(sketch);

```

Pro spuštění lze použít stejný projekt StackBlitz + Vite + TypeScript jako v první lekci. Soubor `index.html` nemusíme měnit.

## **3. Vysvětlení nových konstrukcí**

### **A. Deklarace pole objektů**

```
const bubliny: Bublina[] = [];
```

Tento jediný řádek obsahuje několik důležitých informací.

| Část zápisu | Význam                                    |
| ----------- | ----------------------------------------- |
| `const`     | Proměnné nelze později přiřadit jiné pole |
| `bubliny`   | Název proměnné                            |
| `Bublina[]` | Typ: pole instancí třídy `Bublina`        |
| `[]`        | Nově vytvořené prázdné pole               |

TypeScript tedy ví, že do tohoto pole patří objekty odpovídající třídě `Bublina`.

Například:

```
bubliny.push(new Bublina(100, 100, 40, "red"));
```

je přípustné.

Naopak:

```
bubliny.push(123);
```

způsobí chybu typové kontroly, protože číslo není instancí `Bublina`.

### **B. Přidávání objektů pomocí&#x20;**`push()`

```
bubliny.push(new Bublina(120, 150, 60, "red"));
```

Tento výraz spojuje dvě operace.

Nejprve:

```
new Bublina(120, 150, 60, "red")
```

vytvoří novou instanci třídy `Bublina`.

Poté:

```
bubliny.push(...)
```

vloží odkaz na vytvořený objekt na konec pole.

V našem případě se operace opakuje třikrát.

**Postupné naplňování pole**

Počet vložených objektů: 0

&#x20;Reset

const bubliny: Bublina[] = [];

&#x20;Přidat další bublinu

Důležité je uvědomit si, že `push()` nevytváří instanci. Tu vytváří operátor `new`. Metoda `push()` pouze přidává hodnotu do pole.

### **C. Procházení pole pomocí&#x20;**`forEach()`

```
bubliny.forEach((bublina) => {
  bublina.vykresli(p);
});
```

Metoda `forEach()` postupně prochází všechny prvky pole a pro každý spustí předanou funkci.

V našem případě dostává tato funkce jediný parametr:

```
(bublina)
```

Ten při každém zavolání představuje aktuálně zpracovávanou instanci.

Například:

| Volání | Hodnota parametru `bublina` | Akce          |
| ------ | --------------------------- | ------------- |
| První  | Objekt na indexu 0          | `vykresli(p)` |
| Druhé  | Objekt na indexu 1          | `vykresli(p)` |
| Třetí  | Objekt na indexu 2          | `vykresli(p)` |

Výhodou je, že **nemusíme předem vědět, kolik objektů pole obsahuje**.

Pokud do pole přidáme dvacet dalších instancí, stejný `forEach()` je dokáže všechny vykreslit.

### **D. Co znamená šipková funkce?**

```
(bublina) => {
  bublina.vykresli(p);
}
```

Jde o anonymní šipkovou funkci (*arrow function*).

Pro náš případ ji můžeme chápat jako krátkou funkci, která přijímá jednu bublinu a zavolá její metodu `vykresli()`.

Alternativou je klasická funkce:

```
bubliny.forEach(function (bublina) {
  bublina.vykresli(p);
});
```

Obě varianty mají v tomto případě stejný výsledek.

### **E. Proč máme stále&#x20;**`const`**, když měníme pole?**

Následující zápis je správný:

```
const bubliny: Bublina[] = [];

bubliny.push(new Bublina(100, 100, 40, "red"));
```

Přestože používáme `const`, obsah pole můžeme měnit.

`const` totiž neznamená, že celý objekt nebo pole jsou neměnné. Znamená, že proměnné nelze přiřadit novou hodnotu.

Proto:

```
bubliny.push(new Bublina(200, 100, 50, "blue")); // OK
```

funguje, ale:

```
bubliny = []; // Chyba
```

nefunguje.

## **4. Alternativa: Přímé vytvoření pole objektů**

Náš původní zápis:

```
const bubliny: Bublina[] = [];

bubliny.push(new Bublina(120, 150, 60, "red"));
bubliny.push(new Bublina(300, 100, 90, "blue"));
bubliny.push(new Bublina(480, 200, 45, "green"));
```

můžeme zkrátit:

```
const bubliny: Bublina[] = [
  new Bublina(120, 150, 60, "red"),
  new Bublina(300, 100, 90, "blue"),
  new Bublina(480, 200, 45, "green"),
];
```

Tento zápis je v našem statickém příkladu přehlednější. Obsah pole definujeme přímo při jeho vytvoření.

Pro výuku bych však nejprve použil variantu s `push()`, aby studenti lépe pochopili rozdíl mezi vytvořením objektu a jeho vložením do kolekce.

## **5. Jak získat konkrétní bublinu z pole?**

Každý prvek pole má svůj číselný index. Indexování začíná nulou.

```
bubliny[0] // První bublina
bubliny[1] // Druhá bublina
bubliny[2] // Třetí bublina
```

Protože prvky pole představují objekty, můžeme přistupovat přímo k jejich vlastnostem a metodám:

```
console.log(bubliny[0].barva);
console.log(bubliny[1].prumer);

bubliny[2].vykresli(p);
```

Stejně tak lze upravit vlastnost konkrétního objektu:

```
bubliny[0].barva = "yellow";
bubliny[1].prumer = 120;
```

Pokud tyto změny provedeme před vykreslením, projeví se na grafické ploše.

Je však potřeba počítat s tím, že přístup na neexistující index vrátí `undefined`. V této lekci známe pevný počet prvků, takže se existenci vybraných indexů můžeme snadno ujistit.

## **6. Další možnost: Klasický cyklus&#x20;**`for`

Stejný výsledek jako `forEach()` můžeme získat pomocí známého cyklu:

```
for (let i = 0; i < bubliny.length; i++) {
  bubliny[i].vykresli(p);
}
```

Nebo pomocí `for...of`:

```
for (const bublina of bubliny) {
  bublina.vykresli(p);
}
```

| Způsob      | Charakteristika                            |
| ----------- | ------------------------------------------ |
| `for`       | Máme přímý přístup k indexu prvku          |
| `for...of`  | Jednoduché procházení jednotlivých objektů |
| `forEach()` | Funkcionální zápis s callbackem            |

Pro tuto lekci bych se soustředil na `forEach()`, ale ukázal bych studentům i variantu s klasickým cyklem, kterou již pravděpodobně znají.

plocha(): number {

## **9. Co jsme se naučili a jak pokračovat**

Na konci druhé lekce by studenti měli rozumět tomu, že **instance třídy lze ukládat do pole stejně jako čísla nebo řetězce**. Každá instance přitom nadále obsahuje vlastní stav a poskytuje své metody.

Právě díky tomu můžeme s mnoha objekty pracovat jednotně a nemusíme každou novou bublinu pojmenovávat a samostatně obsluhovat.

Ve třetí fázi bych ponechal stejnou třídu `Bublina`, ale nahradil ručně zapisované instance **automatickým generováním objektů pomocí&#x20;**`Array.from()`**&#x20;a&#x20;**`p.random()`. Studenti tak poznají rozdíl mezi vytvořením jedné instance a hromadným generováním různých instancí a procvičí si šipkové funkce i náhodný výběr hodnot.
